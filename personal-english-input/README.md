# Personal English Input

一个本地优先的 Rime 原型：按回车保存本句已提交的中文，在用户主动运行更新流程时生成句子翻译和个人英语词汇。

## 当前范围

- 记录 Rime 提交的中文，按回车时保存一条句子。
- 支持中英文标点、数字、空格、普通退格、Delete、左右光标移动和中间插入。
- 中英文混输时保持鼠鬚管为当前输入法，用左 Shift 切换其内部英文模式；这样英文也能进入同一条句子记录。
- 未按回车的片段保存在本地缓冲；闲置超过 30 分钟后从新句子开始。
- 遇到上下跨行、Home/End 或 Shift/Option/Command 选区编辑时，放弃该句，避免写入错误内容。
- 原始句子保存在本机。
- 翻译词条默认一个释义，最多两个。
- 候选词英文只读取 `~/Library/Rime/personal_translate.tsv`；未收录的词不显示英文，不回退到 ECDICT 或云端。
- 词组不自动拆分；组成部分只有独立出现时才建立独立词条。

## 目录

- `rime/`：Rime Lua 句子记录器、个人词库 filter 和方案补丁示例。
- `skills/personal-english-lexicon/`：用户主动运行的 Codex Skill，包含本地导入、去重、验证、报告和发布工具。
- `tests/`：确定性存储流程测试。

## 数据位置

运行时数据默认位于：

```text
~/Library/Application Support/personal-english-lexicon/
```

原始句子和个人词库不属于项目源码，不应提交到 Git。

## 当前限制

鼠标点击移动光标不会通知 Rime，因此无法在 Lua 层可靠重建这类编辑。需要修改句中内容时，优先使用左右方向键。

如果切换到 macOS 的 ABC 或其他输入法，Rime 无法看到那些英文按键；请使用鼠鬚管内部英文模式。

第一版只为 Rime 已经能够生成的中文候选添加个人翻译。自动把新词组转换为带拼音的候选词条将在下一阶段实现。
